# CLAUDE.md

## Dependencies

- This is a statically hostable web app. Write code with as few dependencies as possible.
- Prefer vanilla HTML/CSS/JS and browser built-ins over frameworks, libraries, or build tooling. Add a dependency only when explicitly asked or clearly unavoidable.

## Git

- Never commit or push without asking first.
- Keep commit messages short — ideally one sentence.
- No co-author lines or LLM/agent attribution in commits; agent use is assumed.
